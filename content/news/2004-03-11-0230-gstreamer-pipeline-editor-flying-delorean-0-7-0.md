---
title: "GStreamer Pipeline Editor \"Flying Delorean\" 0.7.0 released"
date: 2004-03-11T02:30:00Z
---

The GStreamer team is happy to announce a new release of the
GStreamer Pipeline Editor.
This release brings gst-editor into line with the latest GStreamer API and support for new features such as internationalisation, and better error handling and debugging.

Check out the
[release notes](/releases/gst-editor/0.7.0.html)
or download the
[tar.gz](/src/gst-editor/gst-editor-0.7.0.tar.gz) or
[tar.bz2](/src/gst-editor/gst-editor-0.7.0.tar.bz2) archive.
