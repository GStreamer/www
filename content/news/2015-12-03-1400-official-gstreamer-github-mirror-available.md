---
title: "Official GStreamer GitHub mirror available"
date: 2015-12-03T14:00:00Z
---

Due to popular demand in the past, we now have an official mirror of
all GStreamer GIT repositories on GitHub: [https://github.com/GStreamer](https://github.com/GStreamer).
These are synced every 12-24 hours with the main repositories at
[http://cgit.freedesktop.org/gstreamer/](http://cgit.freedesktop.org/gstreamer/).

Pull requests are not going to be accepted on GitHub and are going to
be closed automatically. Patches should go to Bugzilla as usual, as
well as feature requests and bug reports.

See [/wiki/SubmittingPatches/](/wiki/SubmittingPatches/)
for details and report anything here [https://bugzilla.gnome.org/enter_bug.cgi?product=GStreamer](https://bugzilla.gnome.org/enter_bug.cgi?product=GStreamer)
