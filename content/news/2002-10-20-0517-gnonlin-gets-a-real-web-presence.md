---
title: "Gnonlin gets a real web presence"
date: 2002-10-20T05:17:00Z
---

You can now find the [Gnonlin](http://gnonlin.sourceforge.net) project on the web
with some preliminary information and of course the current source code.
Gnonlin is our companion library for GStreamer for non-linear video editors.
So if you are interested in these kind of applications make sure to visit [Gnonlin on the web](http://gnonlin.sourceforge.net).
