---
title: "GStreamer Core 0.11.0, Base Plugins 0.11.0 unstable release"
date: 2011-08-02T20:59:00Z
---

The GStreamer team announces a new release of the GStreamer core and
gst-plugins-base modules for the 0.11 GStreamer unstable release series.

This is the first release of the unstable 0.11 series that will lead up
to the next 1.0 stable series later this year.

Check out release notes for
[gstreamer core](/releases/gstreamer/0.11.0.html) or
[gst-plugins-base](/releases/gst-plugins-base/0.11.0.html),
or download tarballs for
[gstreamer](/src/gstreamer/gstreamer-0.11.0.tar.bz2) or
[gst-plugins-base](/src/gst-plugins-base/gst-plugins-base-0.11.0.tar.bz2),
